Sobre

Entendo o processo antes de propor a solução

Comecei em implantação de ERP e sustentação de ambientes de TI no interior do Pará. Essa origem definiu meu jeito de trabalhar.

Ao longo do caminho passei por varejo, distribuição, mineração e consultoria. Sou pós-graduado em Engenharia e Arquitetura de Dados com Inteligência Artificial e tenho MBA em Ciência de Dados e Big Data Analytics, sobre uma base de bacharelado em Sistemas de Informação.

Engenharia de Dados · Projeto acadêmico aplicado

Plataforma de Dados Integrada na AWS

Arquitetura em camadas com AWS S3 e pipeline ETL, desenvolvida como projeto aplicado da pós-graduação em Engenharia e Arquitetura de Dados com Inteligência Artificial.

Projeto acadêmico concluído

A proposta organiza o dado desde a entrada até o consumo analítico, usando a arquitetura Medalhão para separar dados brutos, dados tratados e dados prontos para consumo. O foco do trabalho é escalabilidade, governança, qualidade dos dados e apoio à tomada de decisão.

Declaração de escopo: projeto acadêmico autoral concluído em 2025, sem dados corporativos ou de terceiros. A imagem abaixo é uma representação conceitual do case.

  • AWS S3
  • ETL
  • Arquitetura Medalhão
  • Governança
  • Qualidade de dados

Camadas da arquitetura

  • BRONZE

    Recebe os dados na forma mais próxima possível da origem, preservando rastreabilidade e base para reprocessamentos.

  • SILVER

    Concentra padronização, tratamentos e validações necessários para elevar a qualidade e a consistência dos dados.

  • GOLD

    Disponibiliza dados organizados para consumo analítico e suporte à tomada de decisão.
